# Contributing

## Development Workflow

1. Create Issue
2. Design
3. Implement
4. Test
5. Documentation
6. Pull Request
7. Review
8. Merge

---

## Coding Standards

- Follow AGENTS.md.
- Keep modules small.
- Write tests.
- Prefer composition.
- Avoid unnecessary dependencies.

---

## Pull Requests

Every PR should include:

- Description
- Motivation
- Tests
- Documentation updates
- Risk assessment

---

## Code Reviews

Reviewers should verify:

- Architecture
- Correctness
- Performance
- Security
- Maintainability
