## High-Level Overview

Life OS is composed of:

- User Interface
- API Gateway
- AI Orchestration Layer
- Memory Engine
- Knowledge Engine
- Planning Engine
- Automation Engine
- Analytics Engine

These services communicate through an event bus.

- AI-first
- Explainability
- Independent services
- Replaceable LLM providers
